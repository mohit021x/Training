# AWS S3 Basics

## What is Amazon S3?

Amazon S3 (Simple Storage Service) is AWS's fully managed **object storage service**. It is designed to store and retrieve any amount of data from anywhere.

S3 stores data as **objects** inside **buckets**.

- **Bucket**: A container that holds objects.
- **Object**: A file along with its metadata and unique key.

---

## Key Features of Amazon S3

- Highly scalable storage
- 99.999999999% (11 nines) durability
- Secure data storage
- Pay-as-you-go pricing
- Supports versioning and replication
- Static website hosting support
- Multiple storage classes for cost optimization

---

## Buckets and Regions

Every S3 bucket is created in a specific AWS Region.

Example:

```text
Bucket Name: my-website-assets
Region: ap-south-1 (Mumbai)
```

Although a bucket belongs to a single region, S3 provides replication features to copy data to other buckets and regions.

---

## Objects in S3

Each object consists of:

- Object Key (file name/path)
- Data (actual file contents)
- Metadata
- Version ID (if versioning is enabled)

---

# S3 Versioning

Versioning allows multiple versions of an object to be stored.

Benefits:

- Protects from accidental deletion.
- Protects from accidental overwrites.
- Allows restoring previous versions of files.

If Version 3 is deleted accidentally, Version 2 can still be restored.

---

# S3 Replication

Replication automatically copies objects from one bucket to another.

## Cross-Region Replication (CRR)

Copies objects between buckets in different AWS regions.

Use Cases:

- Disaster recovery
- Compliance requirements
- Global data access

---

## Same-Region Replication (SRR)

Copies objects to another bucket within the same AWS region.

Use Cases:

- Log aggregation
- Data ownership separation
- Backup strategies

---

# Bucket Policies

A Bucket Policy is a JSON document attached directly to a bucket that defines permissions.

Bucket policies can:

- Allow public access
- Restrict access to specific users
- Allow access from specific IPs
- Enforce encryption requirements

Example:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-website/*"
    }
  ]
}
```

---

# Static Website Hosting

Amazon S3 can host static websites.

Supported content:

- HTML
- CSS
- JavaScript
- Images

Note:

S3 can host only static content. Dynamic backend code such as Java, Node.js, Python, or PHP must run on services like EC2, ECS, Lambda.

---

# S3 Backup and Snapshots

Although S3 does not provide snapshots in the same way as EBS volumes, data protection can be achieved using:

- Versioning
- Replication
- AWS Backup
- Object Lock

These mechanisms help recover deleted or modified objects and maintain compliance requirements.

# S3 Storage Classes

Storage classes help optimize costs based on how frequently data is accessed.

## 1. S3 Standard

Designed for frequently accessed data.

Features:

- Low latency
- High throughput
- Multi-AZ durability
- Immediate access

Use Cases:

- Websites
- Mobile applications
- Frequently accessed files

---

## 2. S3 Standard-Infrequent Access (S3 Standard-IA)

Designed for data accessed less frequently but requiring rapid retrieval.

Features:

- Lower storage cost than Standard
- Retrieval charges apply
- Multi-AZ durability

Use Cases:

- Backups
- Disaster recovery
- Long-term business data

---

## 3. S3 One Zone-IA

Stores data in a single Availability Zone.

Features:

- Lower cost than Standard-IA
- Immediate access
- Single AZ storage

Use Cases:

- Secondary backups
- Re-creatable data

---

## 4. S3 Glacier Instant Retrieval

For archival data that is rarely accessed but requires instant retrieval.

Features:

- Low-cost archive storage
- Millisecond retrieval

Use Cases:

- Medical records
- Digital media archives
- Archived user data

---

## 5. S3 Glacier Flexible Retrieval

Formerly known as S3 Glacier.

Features:

- Very low-cost archive storage
- Retrieval in minutes to hours

Use Cases:

- Archival storage
- Long-term backups

---

## 6. S3 Glacier Deep Archive

Cheapest S3 storage class.

Features:

- Extremely low storage cost
- Retrieval can take several hours

Use Cases:

- Compliance archives
- Long-term record retention
- Regulatory data storage

---

S3 is one of the most widely used AWS services for storing, securing, serving, and archiving data at scale.
